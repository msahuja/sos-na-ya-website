# Team Photos

Drop headshot photos here to have them show up on the Contact Us page automatically.

**Naming:** each photo must be named after that person's `id` from `team-data.json`, e.g.:

```
jay-ahuja.jpg
mehak-ahuja.png
rimjhim-duggal-stephens.webp
```

`.jpg`, `.jpeg`, `.png`, and `.webp` all work — no need to resize or crop first, the page displays them as a circular 72x72px avatar regardless of the original size/shape (a roughly square photo, cropped around the face, looks best).

Anyone without a matching photo file here just shows a colored initials circle instead — nothing breaks if a photo is missing.
